# Dar Immo - Morocco Real Estate Website

A modern real estate website for the Moroccan market, featuring property listings, city-based search, and bilingual support (Arabic/French).

## Features

- Responsive design optimized for all devices
- RTL support for Arabic language
- Property search functionality
- Featured properties showcase
- City-based property browsing
- Bilingual support (Arabic/French)
- Modern and clean UI

## Setup

1. Clone the repository
2. Create an `images` directory and add the required images
3. Open `index.html` in a web browser

## Development

To modify the website:

- Edit `index.html` for structure changes
- Modify `css/style.css` for styling
- Update `js/main.js` for functionality
